# 安全策略

请**不要**在公开 Issue 中报告安全漏洞。

请通过 GitHub 仓库的 **Security → Report a vulnerability**（私密漏洞报告）提交，说明影响版本、复现步骤和可能的影响。报告中请勿附带真实令牌或用户数据。

我们会尽快确认并修复，修复版本发布后再公开细节。仅最新发布版本提供安全修复。

## Security policy (English)

Please **do not report vulnerabilities in public issues**. Use the repository's **Security → Report a vulnerability** private reporting form. Include affected versions, reproduction steps and potential impact, without real tokens or user data.

We aim to acknowledge reports and fix confirmed issues promptly, disclosing details after a patched release. Only the latest published release receives security fixes.

仓库维护者在公开仓库前应启用 GitHub 私密漏洞报告功能，以便上述入口可用。
Repository maintainers should enable GitHub private vulnerability reporting before making the repository public so this reporting channel is available.
